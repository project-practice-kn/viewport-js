# Работа с backlog

Статусы: `todo`, `in_progress`, `blocked`, `done`. Владелец по умолчанию не назначен.

Перед реализацией прочитай файл задачи и родительский эпик. Зависимости обязательны, если в задаче явно не указано иное. Не закрывай весь эпик, пока остались незавершённые критерии.

В конце реализации заполни раздел «Результат»: что изменилось, проверки, ограничения. Обнови статус в файле задачи, таблице эпика и индексе `tasks/README.md`. При смене scope синхронизируй приёмку и зависимости.

Новые задачи создавай из `templates/task.md`, эпики — из `templates/epic.md`. Не добавляй функции вне MVP. Если работа заблокирована, запиши конкретную зависимость; не изобретай фиктивный успешный результат.
