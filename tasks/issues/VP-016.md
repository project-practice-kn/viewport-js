# VP-016 — Повтор ошибок и очистка незавершённых загрузок

Статус: `done`\
Эпик: [EP04 — Обработка и управление фотографиями](../epics/EP04-processing.md)  
Зависимости: [VP-010](VP-010.md), [VP-013](VP-013.md), [VP-014](VP-014.md)  
Оценка: 1.5 рабочего дня  
Исполнитель: —

## Результат задачи

Идемпотентная очистка просроченных reservations, pending/failed originals и previews; ограниченные порции при uploads и CLI без отдельного worker.

## Критерии приёмки

- [x] Зависшая загрузка после TTL освобождает квоту и удаляет ненужные объекты.
- [x] Сбой S3 допускает повтор без потери возможности найти и удалить объект; повтор очистки безопасен.
- [x] Рестарт во время Sharp/confirm не оставляет вечный processing; retry не создаёт дубликат ready photo.

## Проверка

Прервать процесс между PUT/preview/commit, истечь TTL, отказ DELETE, повтор CLI; сверить БД с S3.

## Результат

Транзакционные failed/released, durable keys, порционная cleanup перед presign и CLI; temporary PUT чистится после TTL. Повтор DELETE безопасен; cleanedAt только после успешной очистки. Smoke моделирует прерывание между preview PUT/commit и отказ DELETE. После рестарта processing чистится по TTL; CLI запускается при остановленном приложении. Полный SIGKILL fault matrix не проводился.
