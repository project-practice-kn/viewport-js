## Результат задачи

Реализовать все 13 доработок из GOAL.md, сохранив модульный монолит, приватность S3 и проверки доступа.

## Критерии приёмки

- [x] Удаление одного/нескольких снимков в draft: подтверждение, повтор после S3-ошибки, квота и новая обложка.
- [x] Серверные состояния незавершённых загрузок, продолжение проверки, отмена и повторный выбор файла; явные причины блокировки публикации.
- [x] Обновление превью редактора при истечении ссылок, ошибке и возвращении во вкладку.
- [x] Защита несохранённых настроек при переходе, назад и закрытии вкладки.
- [x] Восстановление доступа (документированный процесс через организатора для демо) и смена пароля в кабинете.
- [x] Порядок выбора сохраняется независимо от confirm; сортировка по имени и массовое перемещение.
- [x] Большая дополняемая очередь: допустимые файлы загружаются, отклонённые показаны отдельно, повтор всех ошибок.
- [x] Свободное место, объём партии и предупреждение о квоте рядом с загрузчиком.
- [x] Закрытый предпросмотр клиентской страницы и проверка готовности перед публикацией.
- [x] ZIP: число файлов, объём, понятные ошибки и повтор без потери контекста.
- [x] Возврат в исходную галерею после входа с проверкой безопасного адреса.
- [x] Поиск/фильтр галерей, число снимков, дата изменения, быстрые действия.
- [x] Смена ссылки отзывает старый token; действия требуют владельца и подтверждения.

## Проверка

`npm test`, `npm run verify`, HTTP/S3 smoke, браузерные сценарии на мобильном/desktop, две темы, проверки доступа и отказов.

## Результат

Выполнено 2026-11-06. Работа начата в сессии `01a1ad17-b504-71b3-a88c-345341967d76` и завершена после восстановления её контекста и проверки текущего дерева. Исходное состояние — 18 доменных тестов. ### Проверки

- `npm test`: 26/26, включая доступ, конкурентный lifecycle, S3-компенсации, квоту, пароль, порядок и обложку.
- `npm run verify`: 0 ошибок/предупреждений Svelte, форматирование и production-сборка проходят.
- HTTP/S3 smoke в Docker Compose: invite/rate limit, размер PUT, JPEG/PNG/WebP, hash оригиналов и ZIP, CORS/приватность, конкуренция, TTL, unpublish и cleanup проходят.
- Отдельная проверка удаления снимка с временной SQLite и реальным S3: отказ DELETE, повтор, квота, обложка и очистка позднего PUT проходят.
- Headless Chromium / Playwright: 14 основных сценариев и 7 сценариев ошибок/границ; обе темы, просмотрщик, формы без JS, кабинет/редактор/публичная галерея на 390/768/1440 px без горизонтальной прокрутки. Ошибок JavaScript нет.
- Восстановление CLI/HTTP повторно пройдено при завершении на отдельном аккаунте. Существующий файл проверен отдельно: отказ без перезаписи и сообщения об успехе.
- axe-core с тегами WCAG 2 A/AA, 2.1 AA, 2.2 AA: нарушений нет на семи экранах (кабинет, редактор, закрытый предпросмотр, настройки, вход, восстановление, недействительная ссылка); ширина 390 px без overflow.
- Тестовые аккаунты, их записи и S3-ключи удалены по сохранённому журналу IDs; временный HTML восстановления удаляется в finally. Пользовательские данные сохранены.

### Ограничения

Firefox, Safari, физические устройства и ручной скринридер не проверялись; полная матрица остаётся в VP-027. Истечение превью проверено имитацией времени и ошибкой. Уже выданные GET действуют до TTL 120 секунд после смены ссылки/unpublish. Поздний обрыв ZIP отображается менеджером загрузок браузера; компонент объясняет отказ начала потока. Файлы очереди не сохраняются между закрытиями вкладки, серверные состояния сохраняются. Восстановление для демо требует подтверждения владельца организатором, SMTP не добавлен.
