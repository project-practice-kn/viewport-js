# VP-029 — Финальное Docker Compose развёртывание

Статус: `in_progress`\
Эпик: [EP08 — Развёртывание и сдача](../epics/EP08-release.md)  
Зависимости: [VP-028](VP-028.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

Проверить существующий Docker каркас с приложением, приватным S3, HTTPS reverse proxy и persistent SQLite.

## Критерии приёмки

- [x] Чистый build/start и повторный restart сохраняют пользователей, gallery и photos.
- [x] Миграции до startup, health отражает SQLite, контейнер работает без root.
- [ ] ORIGIN build/runtime согласованы; секреты отсутствуют в образе; HTTPS и presigned URL доступны извне.

## Проверка

docker compose up --build -d; полный сценарий; restart; health; проверить содержимое образа.

## Результат

Реализовано локальное Compose-развёртывание: многостадийный образ Node 24, non-root runtime, SQLite/S3 volumes, миграции и настройка CORS до старта, healthchecks, раздельные внутренний и публичный S3 endpoints, smoke в профиле tools.

Проверены UID 1000, healthy у app/s3, отсутствие .env и секретов в metadata образа, полный интеграционный сценарий. После `docker compose down` и `docker compose up --build -d --wait` совпали SHA-256 записей users/galleries/photos и содержимого готовых оригиналов/превью; SQLite quick_check вернул ok.

Для завершения остаются зависимость VP-028 и критерий публичного HTTPS-развёртывания. Команды повторной проверки: [docs/verification.md](../../docs/verification.md).
