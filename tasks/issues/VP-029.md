# VP-029 — Финальное Docker Compose развёртывание

Статус: `in_progress`\
Эпик: [EP08 — Развёртывание и сдача](../epics/EP08-release.md)  
Зависимости: [VP-028](VP-028.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

Проверить существующий Docker каркас с финальным MVP, приватным S3, HTTPS reverse proxy и persistent SQLite.

## Критерии приёмки

- [x] Чистый build/start и повторный restart сохраняют пользователей, gallery и photos.
- [x] Миграции до startup, health отражает SQLite, контейнер работает без root.
- [ ] ORIGIN build/runtime согласованы; секреты отсутствуют в образе; HTTPS и presigned URL доступны извне.

## Проверка

docker compose up --build -d; полный сценарий; restart; health; проверить содержимое образа.

## Результат

По прямому запросу пользователя выполнена локальная часть Docker Compose для checkpoint до финальной production-приёмки: многостадийный образ Node 24, non-root runtime, SQLite/S3 volumes, миграции и CORS до старта, healthchecks, внутренний/публичный S3 endpoints, tools smoke. Старые локальные данные перенесены в volumes с проверкой хэшей; app/s3 healthy, UID 1000, полный Docker smoke проходит. Финальное завершение VP-029 остаётся после VP-028: публичный HTTPS и внешний домен в эту локальную работу не входят. Протокол: docs/verification.md.
