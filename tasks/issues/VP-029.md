## Результат задачи

Проверить существующий Docker каркас с финальным MVP, приватным S3, HTTPS reverse proxy и persistent SQLite.

## Критерии приёмки

- [ ] Чистый build/start и повторный restart сохраняют пользователей, gallery и photos.
- [ ] Миграции до startup, health отражает SQLite, контейнер работает без root.
- [ ] ORIGIN build/runtime согласованы; секреты отсутствуют в образе; HTTPS и presigned URL доступны извне.

## Проверка

docker compose up --build -d; полный сценарий; restart; health; проверить содержимое образа.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
