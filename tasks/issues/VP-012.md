## Результат задачи

PhotoUploader: выбор нескольких файлов, presign, прямой PUT с нужными headers, ограниченный параллелизм и прогресс.

## Критерии приёмки

- [ ] JPEG/PNG/WebP фильтруются до запроса, остальные получают понятную ошибку.
- [ ] У каждого файла статус и прогресс; ограничены uploads in flight; повтор касается только сбойного файла.
- [ ] При доступности VP-013 выполняется confirm; до него UI не выдаёт PUT за готовую фотографию.

## Проверка

Браузер: успешная партия, network offline, отмена, истёкший URL, мобильный выбор файлов.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
