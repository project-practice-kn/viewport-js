# VP-012 — Пакетная загрузка в браузере

Статус: `done`\
Эпик: [EP03 — S3 и загрузки с квотами](../epics/EP03-uploads.md)  
Зависимости: [VP-011](VP-011.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

PhotoUploader: выбор нескольких файлов, presign, прямой PUT с нужными headers, ограниченный параллелизм и прогресс.

## Критерии приёмки

- [x] JPEG/PNG/WebP фильтруются до запроса, остальные получают понятную ошибку.
- [x] У каждого файла статус и прогресс; ограничены uploads in flight; повтор касается только сбойного файла.
- [x] При доступности VP-013 выполняется confirm; до него UI не выдаёт PUT за готовую фотографию.

## Проверка

Браузер: успешная партия, network offline, отмена, истёкший URL, мобильный выбор файлов.

## Результат

PhotoUploader: до 20 файлов, две передачи, per-file прогресс/статусы, отмена и повтор отдельного файла, confirm после PUT. Браузерная реальная загрузка прошла. Полная offline/mobile-device матрица остаётся в проверке качества; см. docs/verification.md.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
