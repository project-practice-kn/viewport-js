## Результат задачи

В том же процессе декодировать оригинал, ограничить пиксели/concurrency, auto-orient, resize, WebP и сохранить preview metadata.

## Критерии приёмки

- [x] JPEG/PNG/WebP распознаются по фактическому содержимому; битый файл и изображение сверх pixel limit отклоняются.
- [x] Оригинал побайтово сохраняется; превью корректно ориентировано и не содержит приватного EXIF.
- [x] Успех переводит photo в ready с dimensions/previewKey; очередь ограничена и перегрузка допускает повтор.

## Проверка

Fixtures всех форматов, EXIF rotation, transparency, corrupted/truncated/decompression bomb; сравнить hash оригинала.

## Результат

Sharp 0.35.5, фактический формат, limitInputPixels, failOn warning, WebP 1800px, autoOrient, без EXIF; ограниченная обработка без очереди. Fixtures JPEG/PNG/WebP, прозрачность, rotation, битые/обрезанные данные, pixel limit и хэш оригинала. npm test и smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
