# VP-026 — Квоты, повторы и восстановление после отказов

Статус: `todo`  
Эпик: [EP07 — Проверка качества](../epics/EP07-quality.md)

Зависимости: [VP-016](VP-016.md), [VP-023](VP-023.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

Проверить параллельные uploads, повтор requests, TTL, restart, S3 ошибки и согласованность DB+objects.

## Критерии приёмки

- [ ] После всех сценариев used+reserved не превышает квоту; нет двойного учёта.
- [ ] Сбой между S3 и SQLite восстанавливается повтором/cleanup; потерянные объекты выявлены.
- [ ] Тесты выполняются на реальном SQLite и изолированном реальном S3 prefix с очисткой.

## Проверка

Два соединения SQLite, конкурентные HTTP, fault injection по шагам upload/delete, stop/restart.

## Результат

Частичное покрытие получено в VP-008: на временной SQLite и локальном S3 проверены отказ DELETE с повтором и PUT, завершившийся после удаления галереи; доменные тесты также проверяют восстановление зависшего processing. Это не заменяет полную матрицу конкурентных запросов, сбоев, остановки и перезапуска. Задача остаётся `todo` до выполнения VP-023 и всех критериев приёмки.
