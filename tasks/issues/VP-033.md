# VP-033 — Отслеживать обновления Svelte и SvelteKit и перейти на TypeScript 7

Статус: `todo`  
Эпик: сквозная техническая задача, вне календарных эпиков  
Зависимости: [VP-001](VP-001.md); для перехода — стабильная поддержка TypeScript 7 в инструментах проекта  
Оценка: регулярная проверка релизов; переход — 0.5–1 рабочий день  
Исполнитель: —

## Результат задачи

Следить за обновлениями Svelte, SvelteKit, svelte-check, Vite и adapter-node. Как только стабильные совместимые версии позволят штатно использовать TypeScript 7 вместо TypeScript 6, обязательно обновить проект. Переход не является необязательным улучшением и не должен теряться при завершении календарных эпиков.

## Порядок работы

1. Проверять релизы не реже одного раза в неделю во время разработки и перед обновлением зависимостей.
2. Сверять API и инструкции миграции через Context7, точные версии, peerDependencies и engines — через npm registry.
3. Пока полноценная поддержка отсутствует, записывать дату проверки и конкретные ограничения в разделе «Результат», оставляя задачу открытой. Наличие экспериментального режима с двумя версиями TypeScript не считается завершённым переходом.
4. После появления поддержки обновить совместимый набор пакетов, конфигурацию и команды проверки типов; сохранить lockfile через npm.
5. Обновить README.md, AGENTS.md, docs/versions.md и docs/architecture.md под фактический стек.

## Критерии приёмки

- [ ] До перехода регулярно фиксируются результаты проверки релизов и оставшиеся ограничения.
- [ ] Установлены совместимые стабильные версии Svelte, SvelteKit и связанных инструментов с поддержкой TypeScript 7.
- [ ] TypeScript 7 используется штатными командами проекта; TypeScript 6 и временные обходные решения больше не требуются.
- [ ] Установка проходит без `--force` и `--legacy-peer-deps`; точные версии закреплены в package.json и package-lock.json.
- [ ] Чистая установка, проверка типов, форматирование, сборка и запуск dev-сервера проходят.
- [ ] Документация соответствует обновлённому стеку; задача и индекс обновлены.

## Проверка

`npm ci`, `npm run verify`, `npm run dev`: стартовая страница открывается без ошибок. Дополнительно выполнить проверки реализованных к моменту перехода функций. Через `npm ls typescript` убедиться, что инструменты больше не требуют TypeScript 6.

## Результат

Переход не выполнен. При каждой проверке записывать дату, найденные версии, ссылки на подтверждение поддержки и оставшиеся ограничения; после перехода — изменения и результаты проверок.
