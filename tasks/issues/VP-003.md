## Результат задачи

Включить email/password, cookie sessions, регистрацию/вход/выход через формы, hook locals и requireUser.

## Критерии приёмки

- [x] Регистрация создаёт пользователя и сессию; вход и выход работают.
- [x] Нет сессии → redirect; выход инвалидирует сессию; неверный пароль не даёт доступ.
- [x] Секрет ≥32 символов хранится в .env; серверный auth не попадает в клиентский bundle.

## Проверка

npm run test:smoke после build; вручную формы с включённым и выключенным JS.

## Результат

Better Auth email/password, cookie sessions, русские SSR-формы регистрации/входа/выхода, hook locals и requireUser. Проверены два аккаунта, неверный пароль, вход HTML-формой, инвалидирование сессии. Context7 для Better Auth недоступен по транспортной ошибке; сверены установленные типы/исходники. npm run test:smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
