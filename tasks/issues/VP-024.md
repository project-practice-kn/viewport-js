# VP-024 — Согласованность публикации и скачивания

Статус: `done`\
Эпик: [EP06 — Оригиналы и ZIP](../epics/EP06-downloads.md)  
Зависимости: [VP-017](VP-017.md), [VP-021](VP-021.md), [VP-023](VP-023.md)  
Оценка: 0.5 рабочего дня  
Исполнитель: —

## Результат задачи

Проверить весь lifecycle с активными uploads/downloads и закрепить правила стабильного состава.

## Критерии приёмки

- [x] Нельзя publish при pending/processing/reservations; нельзя менять состав published.
- [x] Unpublish закрывает новые download requests; уже начатый stream имеет явное документированное поведение.
- [x] Ссылки в UI доступны только при реализованном download; повторные действия не приводят к гонкам.

## Проверка

Параллельные publish/confirm/unpublish/ZIP/delete, два пользователя, просроченный URL.

## Результат

При старте ZIP фиксируется список ready; unpublish закрывает новые публичные запросы, а начатый поток продолжается. Удаление блокируется до закрытия архива. Smoke проверяет архив владельца в draft/published, клиента, чужого пользователя и unpublish; доменный тест — запрет удаления при активном архиве. При активном реальном ZIP smoke проверяет unpublish, отказ нового публичного запроса, запрет удаления и успешное завершение начатого потока. Детерминированный тест с приостановленными операциями S3 проверяет одновременные confirm, publish, ZIP, unpublish и delete, фиксированный состав ZIP и доступ второго пользователя. HTTP smoke дополнительно проверяет гонки confirm/publish и ZIP/unpublish, а также отказ S3 по просроченной подписи. `npm test`, smoke и `npm run verify` прошли.
