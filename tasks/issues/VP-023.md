# VP-023 — Отмена и ошибки потокового скачивания

Статус: `done`\

## Результат задачи

Связать AbortSignal клиента, S3 streams и Archiver; ограничить параллелизм, таймауты и корректное освобождение ресурсов.

## Критерии приёмки

- [x] Отмена клиента прекращает S3 чтение и Archiver, освобождает слот ZIP.
- [x] Ошибка до headers даёт контролируемый ответ; после headers обрывает ответ без ложного успеха.
- [x] Ограничение одновременных ZIP и повтор после сбоя работают.

## Проверка

Медленный клиент, разрыв TCP, S3 404/timeout посередине, несколько архивов; наблюдать память/handles.

## Результат

Реализованы отмена источника и Archiver, таймаут, ограничение параллельных архивов, освобождение слота и обработка ошибок. `npm test` проверяет отмену ReadableStream, отказ S3 до ответа и на втором файле, лимит и повтор. Smoke с реальным S3 прошёл. Smoke дополнительно удерживает три ZIP с файлом 8 МиБ, проверяет 429 для четвёртого, отмену и реальный TCP-разрыв с последующим повтором. По решению пользователя измерение памяти и handles на больших архивах не выполнялось.
