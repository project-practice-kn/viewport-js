## Результат задачи

Связать AbortSignal клиента, S3 streams и Archiver; ограничить параллелизм, таймауты и корректное освобождение ресурсов.

## Критерии приёмки

- [ ] Отмена клиента прекращает S3 чтение и Archiver, освобождает слот ZIP.
- [ ] Ошибка до headers даёт контролируемый ответ; после headers обрывает ответ без ложного успеха.
- [ ] Одновременные ZIP не вызывают линейного роста памяти; повтор после сбоя работает.

## Проверка

Медленный клиент, разрыв TCP, S3 404/timeout посередине, несколько архивов; наблюдать память/handles.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
