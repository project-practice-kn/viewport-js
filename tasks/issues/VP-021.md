## Результат задачи

GET /api/downloads/[token]/[photoId] проверяет доступ и возвращает redirect на presigned GET с Content-Disposition.

## Критерии приёмки

- [x] Скачанный файл совпадает с исходником по hash, имя и Unicode корректны.
- [x] Чужой photoId, draft, unknown token и не-ready photo → 404.
- [x] Проверка повторяется при каждом запросе; короткий TTL; download ответ не кэшируется публично.

## Проверка

Проверить JPEG/PNG/WebP, Unicode и unsafe filename, hash исходника, token другой галереи.

## Результат

Каждый GET проверяет token/published/photo membership, redirect на presigned GET 120с с безопасным Unicode Content-Disposition и no-store. Проверены JPEG/PNG/WebP по SHA-256, чужой photo, unknown token и unpublish. Внешний redirect явно разрешает только origin настроенного S3 endpoint. npm test:smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
