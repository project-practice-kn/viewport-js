## Результат задачи

GET /api/downloads/[token]/[photoId] проверяет доступ и возвращает redirect на presigned GET с Content-Disposition.

## Критерии приёмки

- [ ] Скачанный файл совпадает с исходником по hash, имя и Unicode корректны.
- [ ] Чужой photoId, draft, unknown token и не-ready photo → 404.
- [ ] Проверка повторяется при каждом запросе; короткий TTL; download ответ не кэшируется публично.

## Проверка

Проверить JPEG/PNG/WebP, Unicode и unsafe filename, hash исходника, token другой галереи.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
