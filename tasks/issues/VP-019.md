# VP-019 — PhotoViewer и мобильная навигация

Статус: `in_progress`\
Эпик: [EP05 — Публичная галерея](../epics/EP05-sharing.md)  
Зависимости: [VP-018](VP-018.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

Lightbox с увеличением, предыдущим/следующим фото, Escape, стрелками, focus trap и возвратом фокуса.

## Критерии приёмки

- [ ] Открытие и закрытие не теряет позицию сетки; работает клавиатура и touch.
- [ ] Описания/номера фото доступны assistive technologies, modal корректно управляет фокусом.
- [ ] Не загружаются сразу все оригиналы; сетка lazy-load с зарезервированными dimensions.

## Проверка

Keyboard-only сценарий, экран 390px, zoom, reduced motion, первая/последняя фотография.

## Результат

Подключён PhotoSwipe 5.4.4 к SSR-сетке превью, добавлены русские подписи, имя и номер фотографии, скачивание текущего оригинала и сообщение об ошибке. Просмотр без JS сохраняет ссылку на превью. Выполнены `npm test` и `npm run verify`; на изолированном стенде Chromium проверены открытие, стрелка вправо, увеличение, смена ссылки скачивания, Escape и возврат фокуса. На реальной публичной галерее ещё требуется проверить сенсорные жесты, скринридер, обе темы, reduced motion, границы галереи и поведение без JS; до этого задача не считается завершённой.

Увеличение кнопкой настроено на 2× относительно размера на экране, жестом — до 4×. В Chromium на изолированном стенде измерено двукратное увеличение; `npm run verify` выполнен успешно. Качество ограничено разрешением превью.

Просмотрщик подключён также к сетке фотографа для черновиков и опубликованных галерей. Общая настройка используется обеими страницами; в редакторе просмотр работает и без публикации. На изолированных стендах Chromium проверены открытие, переход, увеличение и возврат фокуса, а также сохранение скачивания в публичном просмотрщике; `npm run verify` выполнен успешно.
