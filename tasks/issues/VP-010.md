## Результат задачи

Сервис резервирования в BEGIN IMMEDIATE: ready originals + активные резервы, TTL, статусы, освобождение.

## Критерии приёмки

- [x] Два параллельных запроса около лимита не могут оба занять одно свободное место.
- [x] Повтор confirm/release не удваивает used bytes и не освобождает чужой резерв.
- [x] Граничные размеры, число файлов, истечение и отсутствие места обрабатываются явно.

## Проверка

Реальный SQLite, два соединения/параллельные HTTP запросы, лимит−1/лимит/лимит+1, повтор release.

## Результат

BEGIN IMMEDIATE резервирует ready originals + активные reservations; лимиты файлов/партий/pending и TTL. Два конкурентных HTTP запроса на последние 100 байт дают один 200 и один 409. Cancel/failure освобождает квоту ровно один раз и сохраняет ключи для cleanup. npm test и smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
