## Результат задачи

Сервис резервирования в BEGIN IMMEDIATE: ready originals + активные резервы, TTL, статусы, освобождение.

## Критерии приёмки

- [ ] Два параллельных запроса около лимита не могут оба занять одно свободное место.
- [ ] Повтор confirm/release не удваивает used bytes и не освобождает чужой резерв.
- [ ] Граничные размеры, число файлов, истечение и отсутствие места обрабатываются явно.

## Проверка

Реальный SQLite, два соединения/параллельные HTTP запросы, лимит−1/лимит/лимит+1, повтор release.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
