# VP-038 — Миниатюры, порционная галерея и сортировка кабинета

Статус: `done`\
Эпик: [EP07 — Проверка качества](../epics/EP07-quality.md)\
Зависимости: VP-014, VP-018, VP-037\
Оценка: 2 рабочих дня\
Исполнитель: Codex

## Результат задачи

Уменьшить начальный трафик больших галерей и упростить поиск съёмок в кабинете.

## Критерии приёмки

- [x] Новые снимки получают отдельную WebP-миниатюру до 480 px; оригинал и крупное превью не меняются. Старые снимки используют прежнее превью.
- [x] Клиентская галерея и закрытый предпросмотр сначала получают 24 фотографии; следующие порции загружаются по запросу. Без JavaScript доступны ссылки на следующую страницу.
- [x] Сетка использует миниатюры, просмотрщик — крупные превью. Новые запросы проверяют публикацию или владельца и состав порции.
- [x] В кабинете видны обложка и объём готовых оригиналов; доступны сортировки по дате изменения, названию и размеру. Дата после загрузки страницы показывается в часовом поясе браузера.
- [x] Миниатюры входят в повторяемую очистку при удалении и ошибке обработки.

## Проверка

`npm test`, `npm run verify`, Docker Compose smoke, открыть галерею с более чем 24 снимками с JavaScript и без него; проверить доступ к порциям после снятия публикации и для чужого пользователя.

## Результат

Выполнено 2026-11-06. Реализованы отдельные миниатюры, порционная выдача готовых снимков, обложки и сортировка кабинета. Для обложек кабинет использует закрытый маршрут с подписью S3-ссылки в момент загрузки изображения. Docker-сборка использует локальные заголовки Node для `better-sqlite3`: это устранило зависимость повторной сборки от доверия к сертификату внешнего сервера заголовков.

- `npm test`: 27/27. Проверены размер миниатюры, порции ready-снимков, сумма размеров, сортировки и повторяемое удаление S3-объектов.
- `npm run verify`: 0 ошибок и предупреждений Svelte; форматирование и production-сборка проходят.
- `docker compose up --build -d --wait`: app и S3 healthy; `/health` вернул `{"status":"ok"}`.
- `docker compose --profile tools run --rm smoke`: реальный S3, приватная обложка и чужой доступ, JPEG/PNG/WebP и их миниатюры, галерея из 25 снимков (24+1 в HTML и API), ограничение порции, ошибка несовпадения и 404 после снятия публикации. Тестовые записи и объекты удалены в `finally`.

Существующие фото без `thumbnail_key` используют крупное превью, пока их не загрузят заново. Редактор по-прежнему получает весь список для массового выбора и изменения порядка; порционная выдача относится к клиентской галерее и закрытому предпросмотру. Автоматический браузерный прогон кнопки с JavaScript и отображения часового пояса не выполнялся; HTTP/SSR и серверная часть порций проверены smoke.
