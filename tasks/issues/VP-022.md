## Результат задачи

GET /api/downloads/[token]/archive использует Archiver и S3 streams; ограничения объёма/количества/активных ZIP.

## Критерии приёмки

- [x] ZIP не пишется на диск/S3 и не собирается целиком в памяти; backpressure соблюдается.
- [x] Безопасные имена без traversal; одинаковые filenames получают суффиксы.
- [x] Галерея сверх лимита отклоняется до начала ответа; архив раскрывается стандартным инструментом.

## Проверка

Реальный S3 → ZIP → unzip -t; сравнить hashes, дубликаты/Unicode/../ filenames, размер около лимита.

## Результат

Реализован потоковый ZIP64 через Archiver с проверкой доступа к публичной и приватной галерее, безопасными уникальными именами и ограничениями размера, количества и параллельности. `npm test`, `npm run verify` и smoke с реальным S3 прошли: хэши трёх форматов совпали, `unzip -t` прошёл. Имена Unicode, пути и дубликаты проверены доменным тестом. Нагрузочная проверка галереи около 5 ГиБ остаётся в VP-028.
