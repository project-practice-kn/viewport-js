## Результат задачи

GET /api/downloads/[token]/archive использует Archiver и S3 streams; ограничения объёма/количества/активных ZIP.

## Критерии приёмки

- [ ] ZIP не пишется на диск/S3 и не собирается целиком в памяти; backpressure соблюдается.
- [ ] Безопасные имена без traversal; одинаковые filenames получают суффиксы.
- [ ] Галерея сверх лимита отклоняется до начала ответа; архив раскрывается стандартным инструментом.

## Проверка

Реальный S3 → ZIP → unzip -t; сравнить hashes, дубликаты/Unicode/../ filenames, размер около лимита.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
