## Результат задачи

Добавить согласованный SQLite backup/restore, хранение backup вне volume и сверку с S3.

## Критерии приёмки

- [ ] Backup активного WAL корректен через backup API или приложение явно остановлено.
- [ ] Восстановление проверено в чистом volume; пользователи, metadata и доступ к объектам сохранены.
- [ ] Runbook содержит update/migrate/rollback, очистку и диагностику; разрушительные команды явно обозначены.

## Проверка

Снять backup, восстановить отдельно, сравнить метаданные и скачать контрольный оригинал.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
