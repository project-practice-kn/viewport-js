# VP-020 — Две темы, истечение ссылок и состояния галереи

Статус: `done`\
Эпик: [EP05 — Публичная галерея](../epics/EP05-sharing.md)  
Зависимости: [VP-018](VP-018.md), [VP-019](VP-019.md)  
Оценка: 0.5 рабочего дня  
Исполнитель: —

## Результат задачи

Применить gallery theme при первом открытии; позволить локальное переключение, обрабатывать истёкшие превью и ошибки сети.

## Критерии приёмки

- [x] Нет мигания неверной темы; учитывается выбор посетителя, контраст достаточен.
- [x] Долго открытая gallery получает свежие URL через повторную проверку токена/published, без утечки ссылок draft.
- [x] Сбой превью и отсутствие gallery имеют понятные состояния без циклических повторов.

## Проверка

Сокращённый TTL, долго открытая вкладка, unpublish, offline, обе темы и reload.

## Результат

Тема посетителя сохраняется в cookie и применяется при SSR; переключение работает без JS. Превью обновляются при возвращении к старой вкладке и ошибке загрузки; endpoint повторно проверяет публикацию, а сетевой сбой и снятие публикации показывают понятное состояние. В Chromium на изолированном стенде проверены обновление после имитации времени, восстановление открытого PhotoSwipe, ограничение повторов, offline и 404. Smoke с реальным S3 проверил выдачу и срок новых URL, сохранение темы и отказ после unpublish; `npm test` и `npm run verify` прошли. Полная матрица физических устройств и скринридеров остаётся в VP-027; сценарий истечения проверен имитацией времени и ошибки, а не ожиданием реальных 120 секунд.

Ограничение автоматического повтора учитывает отдельные изображения и сбрасывается после их успешной загрузки. В Chromium проверены последовательные сбои двух снимков, постоянная ошибка одного снимка и восстановление в открытом PhotoSwipe.

Ошибки, возникшие во время обновления, сохраняются и повторяются после ответа даже при неизменившихся подписанных URL. В Chromium проверены два одновременных HTTP-сбоя с последующим восстановлением и постоянный отказ без цикла; smoke проверяет работу подписанного S3 URL с фрагментом повтора.
