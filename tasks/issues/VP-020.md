## Результат задачи

Применить gallery theme при первом открытии; позволить локальное переключение, обрабатывать истёкшие превью и ошибки сети.

## Критерии приёмки

- [ ] Нет мигания неверной темы; учитывается выбор посетителя, контраст достаточен.
- [ ] Долго открытая gallery получает свежие URL через повторную проверку токена/published, без утечки ссылок draft.
- [ ] Сбой превью и отсутствие gallery имеют понятные состояния без циклических повторов.

## Проверка

Сокращённый TTL, долго открытая вкладка, unpublish, offline, обе темы и reload.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
