# VP-008 — Удаление галереи и фотографий с компенсациями

Статус: `done`\
Эпик: [EP02 — Управление галереями](../epics/EP02-galleries.md)  
Зависимости: [VP-007](VP-007.md)  
Оценка: 1.5 рабочего дня  
Исполнитель: —

## Результат задачи

Удаление draft и его фотографий с повторяемой очисткой SQLite и S3.

## Критерии приёмки

- [x] Пустой draft удаляется только владельцем после явного действия в UI.
- [x] После подключения S3 удаляются оригинал, превью и reservation; сбой не скрывает оставшиеся объекты.
- [x] Повтор удаления безопасен; не удаляются published или галерея с активной обработкой.

## Проверка

Проверить пустой draft, снимки, ограничения доступа, активную обработку, отказ S3 и повтор удаления.

## Результат

Добавлены подтверждение в редакторе и повторяемое удаление всех объектов и записей. Признак удаления сохраняется в SQLite и блокирует новые изменения; при ошибке S3 ключи остаются для повтора. Удаление запрещено при обработке и до истечения резервов загрузок (по умолчанию до 30 минут), чтобы выданный PUT не оставался действительным. При удалении истёкший зависший processing восстанавливается автоматически, а действительно активный остаётся защищённым. Ключи временных загрузок удалённой галереи сохраняются бессрочно: cleanup проверяет их повторно, поскольку PUT может завершиться после удаления. При отсутствии новых загрузок нужен периодический запуск CLI cleanup.

Проверены 16 доменных тестов, включая форму без JS, owner, published, processing, срок резерва и отказ S3. Отдельный тест на локальном SeaweedFS с временной SQLite проверил удаление трёх реальных объектов после искусственного отказа и повтора. `npm run verify` проверяет типы, форматирование и сборку. Повторная проверка на реальном S3 подтвердила очистку PUT, начатого до удаления и завершённого после него. Полный браузерный сценарий отдельно не проверялся.

По замечанию ревью очистка ключей удалённых галерей вынесена из ожидания presign в один ограниченный фоновый проход. Тест удерживает DELETE незавершённым и проверяет, что presign отвечает, а параллельный проход не запускается.
