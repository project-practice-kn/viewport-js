# VP-017 — Токены, публикация и публичная проверка доступа

Статус: `done`\
Эпик: [EP05 — Публичная галерея](../epics/EP05-sharing.md)  
Зависимости: [VP-007](VP-007.md), [VP-015](VP-015.md), [VP-016](VP-016.md)  
Оценка: 0.5 рабочего дня  
Исполнитель: —

## Результат задачи

randomBytes(32) base64url + unique token, actions publish/unpublish, общая проверка token/published/ready.

## Критерии приёмки

- [x] Publish готовой gallery выдаёт /g/{token}; draft не имеет публичного доступа.
- [x] Unpublish немедленно закрывает новые запросы страницы/скачивания; состав вновь редактируем.
- [x] Истёкшие уже выданные URL имеют документированный TTL; токен не попадает в логи.

## Проверка

Приватное окно: unknown token/draft/unpublish → 404, publish → данные; коллизия уникального token.

## Результат

randomBytes(32) base64url с SQLite UNIQUE, publish/unpublish actions и единые проверки token/published/ready. Draft/unknown/unpublish дают 404, GET TTL 120с; dev request logs отключены для защиты токенов. npm test и smoke.
