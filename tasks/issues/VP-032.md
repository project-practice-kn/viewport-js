## Результат задачи

Пройти весь MVP, оформить release checklist, описание архитектуры, демонстрационные данные и план презентации.

## Критерии приёмки

- [ ] Регистрация → draft → партия → previews → cover/sort → publish → client view → original/ZIP → unpublish/delete проходят.
- [ ] Репозиторий запускается с нуля по README, задачи и ограничения соответствуют реализации.
- [ ] Подготовлен сценарий демонстрации и текстовый план защиты; нет требований масштабирования вне MVP.

## Проверка

Чистый checkout/Compose, два браузерных контекста, npm run verify, ручной полный сценарий. Презентационный файл — отдельный артефакт при необходимости.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
