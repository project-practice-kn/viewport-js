## Результат задачи

Сервис и server actions редактирования с валидацией; UI настроек и feedback успешного сохранения.

## Критерии приёмки

- [ ] Название 1–120, описание до согласованного лимита, тема только light/dark; ограничения серверные.
- [ ] Каждый action проверяет сессию и владельца; ошибка сохраняет введённые значения.
- [ ] Сохранённые данные переживают reload; представлены loading/error/success состояния.

## Проверка

Два аккаунта, длинные/пустые строки, неверная тема, HTML в тексте; npm run verify.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
