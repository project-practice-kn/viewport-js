## Результат задачи

Сервис и server actions редактирования с валидацией; UI настроек и feedback успешного сохранения.

## Критерии приёмки

- [x] Название 1–120, описание до согласованного лимита, тема только light/dark; ограничения серверные.
- [x] Каждый action проверяет сессию и владельца; ошибка сохраняет введённые значения.
- [x] Сохранённые данные переживают reload; представлены loading/error/success состояния.

## Проверка

Два аккаунта, длинные/пустые строки, неверная тема, HTML в тексте; npm run verify.

## Результат

Настройки названия, описания до 2000 символов и темы light/dark; server actions, сохранение введённых значений при ошибке, feedback и enhanced saving. Published сначала снимается с публикации. npm test, check, smoke.
