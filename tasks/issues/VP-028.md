## Результат задачи

Проверить разумную максимальную партию/галерею на целевом Node контейнере, лимиты Sharp/ZIP, исправить блокирующие дефекты.

## Критерии приёмки

- [ ] Зафиксированы измеримые время/RSS при выбранных лимитах, без OOM на сценариях MVP.
- [ ] Build/server logs не содержат необработанных ошибок и клиент не тянет серверные зависимости.
- [ ] Все найденные критические/высокие дефекты закрыты; остальные явно записаны с приоритетом.

## Проверка

npm run verify; целевая партия и параллельные ZIP в Docker; зафиксировать параметры и результаты.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
