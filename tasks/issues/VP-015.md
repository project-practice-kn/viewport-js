## Результат задачи

Сетка фотографий в редакторе, обложка и сохранение порядка; server actions и доступная альтернатива drag-and-drop.

## Критерии приёмки

- [ ] Обложкой может быть только ready photo той же gallery.
- [ ] Сортировка атомарно сохраняется, сервер отклоняет дубликаты/чужие id/пропущенные фото.
- [ ] Published отклоняет изменение; мобильная и клавиатурная сортировка работают.

## Проверка

Два владельца, чужой cover, reorder неполного набора, reload, клавиатура и touch.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
