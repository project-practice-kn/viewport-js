## Результат задачи

Сетка фотографий в редакторе, обложка и сохранение порядка; server actions и доступная альтернатива drag-and-drop.

## Критерии приёмки

- [x] Обложкой может быть только ready photo той же gallery.
- [x] Сортировка атомарно сохраняется, сервер отклоняет дубликаты/чужие id/пропущенные фото.
- [x] Published отклоняет изменение; мобильная и клавиатурная сортировка работают.

## Проверка

Два владельца, чужой cover, reorder неполного набора, reload, клавиатура и touch.

## Результат

Сетка редактора, ready cover этой галереи, автоматическая первая обложка, кнопки перемещения и атомарный полный reorder с проверкой набора. Owner/published checks. npm test, smoke; мобильная сетка в браузере, обычные HTML-кнопки доступны с клавиатуры.
