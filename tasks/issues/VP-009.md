# VP-009 — Интеграция приватного S3

Статус: `done`\

## Результат задачи

Поверх ленивого клиента реализовать put/head/get/delete/presign и серверную генерацию ключей; описать bucket CORS и права.

## Критерии приёмки

- [x] Приватный объект нельзя открыть анонимно без подписи; подписанные PUT/GET работают в браузере.
- [x] S3-compatible endpoint доступен и браузеру, и серверу; ключ/filename из клиента не управляет путём.
- [x] Интеграционная проверка использует отдельный тестовый prefix и очищает объекты.

## Проверка

Реальный приватный тестовый bucket: PUT → HEAD → GET → DELETE, CORS из браузера.

## Результат

Ленивый AWS SDK, приватные временные/принятые ключи, put/head/read/delete/presign, setup bucket CORS. Настоящий SeaweedFS 4.48: CORS preflight, anonymous 403, PUT/HEAD/GET/DELETE и браузерный PUT. Docker daemon недоступен; проверен бинарный запуск. npm run test:smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
