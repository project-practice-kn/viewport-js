## Результат задачи

Поверх ленивого клиента реализовать put/head/get/delete/presign и серверную генерацию ключей; описать bucket CORS и права.

## Критерии приёмки

- [ ] Приватный объект нельзя открыть анонимно без подписи; подписанные PUT/GET работают в браузере.
- [ ] S3-compatible endpoint доступен и браузеру, и серверу; ключ/filename из клиента не управляет путём.
- [ ] Интеграционная проверка использует отдельный тестовый prefix и очищает объекты.

## Проверка

Реальный приватный тестовый bucket: PUT → HEAD → GET → DELETE, CORS из браузера.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
