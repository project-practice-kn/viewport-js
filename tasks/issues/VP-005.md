## Результат задачи

Минимальный вертикальный срез кабинета: список из SQLite, форма названия и страница созданного черновика.

## Критерии приёмки

- [x] После создания галерея сохранена в SQLite и видна после reload.
- [x] Название пустое или длиннее 120 символов отклоняется на сервере.
- [x] Запрос другого владельца даёт 404; список не содержит чужих галерей.

## Проверка

npm run test; npm run test:smoke.

## Результат

Список только собственных галерей, создание и SSR-страница draft из SQLite. Серверная валидация названия и owner 404. npm test и test:smoke.
