# VP-025 — Матрица доступа и входные данные

Статус: `todo`  
Эпик: [EP07 — Проверка полного MVP](../epics/EP07-quality.md)  
Зависимости: [VP-024](VP-024.md)  
Оценка: 1 рабочего дня  
Исполнитель: —

## Результат задачи

Интеграционные тесты auth, ownerId, tokens, photo membership, CSRF и неверных входных данных на всех handlers.

## Критерии приёмки

- [ ] Для каждого handler проверены anonymous/owner/other owner и draft/published.
- [ ] Нельзя подменить S3 key, galleryId или photoId; ошибки не раскрывают чужие данные.
- [ ] Пароли/токены/подписанные URL не попадают в логи; cookie и same-origin проверки не отключены.

## Проверка

Табличные HTTP тесты с двумя аккаунтами; cross-origin POST и malformed multipart/JSON.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
