## Результат задачи

POST /api/uploads/presign принимает galleryId и метаданные партии, резервирует место и возвращает id/URL/requiredHeaders/expiresAt.

## Критерии приёмки

- [x] Владелец draft может запросить ограниченную партию JPEG/PNG/WebP; MIME/size/name валидируются.
- [x] Нет сессии/чужая gallery/published/квота → отказ до выдачи URL.
- [x] Ключ генерируется сервером; короткий TTL; сбой подписи компенсирует резервы.

## Проверка

HTTP интеграция с S3; превышение размера/партии/квоты, ошибка провайдера, подмена galleryId.

## Результат

POST presign проверяет сессию, owner/draft, MIME/name/size, атомарную квоту и выдаёт URL/headers/expiry. PUT до 300 секунд; ключ генерируется сервером; ошибка подписи переводит созданные фото в failed и releases резервы. npm test:smoke.

Общий протокол и ограничения: [docs/verification.md](../../docs/verification.md).
