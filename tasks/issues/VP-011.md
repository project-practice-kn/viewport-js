## Результат задачи

POST /api/uploads/presign принимает galleryId и метаданные партии, резервирует место и возвращает id/URL/requiredHeaders/expiresAt.

## Критерии приёмки

- [ ] Владелец draft может запросить ограниченную партию JPEG/PNG/WebP; MIME/size/name валидируются.
- [ ] Нет сессии/чужая gallery/published/квота → отказ до выдачи URL.
- [ ] Ключ генерируется сервером; короткий TTL; сбой подписи компенсирует резервы.

## Проверка

HTTP интеграция с S3; превышение размера/партии/квоты, ошибка провайдера, подмена galleryId.

## Результат

Заполняется после реализации: изменения, выполненные проверки, ограничения.
