## Результат задачи

Реализовать /g/[token]/+page.server.ts и +page.svelte: заголовок, описание, обложка и адаптивная сетка ready previews.

## Критерии приёмки

- [x] HTML без JS содержит контент gallery; query исключает не-ready photos.
- [x] Обложка и порядок соответствуют редактору; используются приватные короткие S3 URLs.
- [x] Нет публичного кэширования подписанных URL и нет утечки owner email/служебных данных.

## Проверка

curl HTML, браузер без JS, 390px/desktop, 0/1/100 фото, запрос после unpublish.

## Результат

Публичная SSR-страница с названием, описанием, темой, обложкой и упорядоченными ready previews. Нет owner email/служебных ключей в page data; private no-store и same-origin referrer policy. HTTP HTML и браузер 390px/desktop, реальные изображения. Большие галереи и долгие сессии — дальнейшая проверка качества.
