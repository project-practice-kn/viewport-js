- Конец недели 4: партии фотографий, готовые превью, обложка/порядок, атомарная квота и восстановление ошибок.
- Конец недели 6: полный сценарий фотограф → клиент → оригинал и ZIP.
- Конец недели 7: матрица отказов/доступа, темы, мобильный UI, измеренные лимиты.
- Конец недели 8: HTTPS + Compose + приватный S3, backup/restore, guides и демонстрация.

## Как вести задачи

Файл каждой задачи находится в `issues/`, эпики — в `epics/`. Статусы: `todo → in_progress → done`, `blocked` — с конкретной причиной и следующим действием. Берите задачу только после её зависимостей. В каждом файле есть результат, приёмка, проверка и место для фактического отчёта.

После выполнения обновите статус задачи, родительский эпик и эту таблицу. Общая Definition of Done — [CONTRIBUTING.md](../CONTRIBUTING.md). Новые документы создавайте из [шаблона задачи](templates/task.md) или [шаблона эпика](templates/epic.md).

## Приоритеты при нехватке времени

Нельзя сокращать owner/token checks, атомарные квоты, проверку фактических файлов, cleanup, приватность S3 и корректное закрытие ZIP streams. Сначала упрощать декоративные эффекты, drag-and-drop (оставить кнопки порядка), вариации оформления и презентационные украшения.

За границами MVP: RAW/HEIC, OAuth, оплата, роли команд, пароль на клиентскую gallery, водяные знаки, выбор избранного, кастомные домены, CDN, отдельные воркеры/брокеры и масштабирование.
