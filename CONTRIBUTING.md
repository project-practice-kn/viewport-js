# Разработка

Сейчас репозиторий содержит только шаблон. Запуск: Node 24, npm ci, npm run dev. Никакая конфигурация внешних сервисов не требуется.

## Порядок работы

Выбирайте задачи из tasks/README.md с учётом зависимостей и приоритетов.

При реализации задачи:

1. Прочитать AGENTS.md, файл задачи и зависимости.
2. Отметить задачу in_progress.
3. Реализовать результат по критериям приёмки.
4. Выполнить относящиеся к нему проверки и npm run verify.
5. Обновить задачу, эпик и индекс; описать фактический результат.

## Definition of Done будущих задач

- Критерии задачи выполнены; заглушка или установленная зависимость не считается функцией.
- Проверки типов, форматирование и сборка проходят.
- Для данных проверены доступ, владельцы, состояния и ошибки; для UI — мобильный экран, темы и доступность.
- Для SQLite сохранены миграции; для S3/Sharp/ZIP проверен реальный сценарий и очищены временные данные.
- Документация и статусы соответствуют реализации; секретов и локальных данных в Git нет.

Сейчас тестов бизнес-функций нет, поскольку сами функции не реализованы. tests/ оставлен для будущей работы.
