# Загрузка и обработка фотографий

`index.ts` резервирует квоту в SQLite, выдаёт временные PUT URL, подтверждает содержимое через Sharp и сохраняет оригинал/превью. Обработка ограничена числом активных confirm; повтор ready идемпотентен. Очистка сохраняет ключи для повторного DELETE при сбое S3. CLI очистки запускается при остановленном приложении.

Позиции назначаются при резервировании, поэтому завершение confirm не меняет порядок выбора. `unfinished` показывает владельцу сохранённые серверные состояния, `refreshGalleryUploads` очищает истёкшие резервы этой галереи при открытии редактора. `assertUploadGallery` проверяет принадлежность снимка для actions восстановления. Работающий confirm очистка пропускает.
