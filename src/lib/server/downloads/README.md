# Скачивание

`index.ts` проверяет доступ и ограничения, затем последовательно читает оригиналы из S3 и передаёт ZIP64 через Archiver. `active.ts` ограничивает параллельность и блокирует удаление галереи во время скачивания. Ошибки и отмена закрывают источник, архив и слот. Параметры и поведение после unpublish описаны в [архитектуре](../../../../docs/architecture.md).
