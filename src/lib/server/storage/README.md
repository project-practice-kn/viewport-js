# S3

`index.ts` предоставляет ленивый клиент для put/head/read/delete и отдельный клиент для подписи URL. Серверные операции используют S3_ENDPOINT, подпись — S3_PUBLIC_ENDPOINT с fallback на S3_ENDPOINT. Ключи генерируют серверные сервисы, имена скачивания очищаются через safeFilename.

`presignPut` принимает точный размер файла и включает `Content-Length`/`Content-Type` в SigV4. Браузер выставляет длину самостоятельно по File; возвращаемые `requiredHeaders` содержат только разрешённый для JS Content-Type. Другой размер должен отклоняться S3 до confirm; интеграционный smoke проверяет ±1 байт и отсутствие созданного объекта после отказа.
