# Галереи

`index.ts` содержит проверки владельца и draft, создание/список/редактирование, обложку, порядок и атомарные publish/unpublish. Здесь же находятся проверка публичного токена, представление ready photos и выдача подписанной ссылки оригинала. Публичные ответы не содержат email владельца и внутренних S3-ключей.

`removePhotos` удаляет выбранные ready-снимки черновика с устойчивой отметкой удаления и повтором S3, обновляет обложку и освобождает квоту после успешной очистки. `sortByName` и `moveMany` используют общий проверяемый reorder. `rotateLink` отзывает прежний публичный token. Список кабинета поддерживает поиск, статус, число готовых снимков и дату изменения.

`publicPhotoPage` и `ownedPhotoPage` проверяют доступ, параметры порции, маркер предыдущего снимка и неизменность состава после подписи S3-ссылок. HTTP endpoints передают в сервис токен либо ID владельца и возвращают результат.
