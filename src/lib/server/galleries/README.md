# Галереи

`index.ts` содержит проверки владельца и draft, создание/список/редактирование, обложку, порядок и атомарные publish/unpublish. Здесь же находятся проверка публичного токена, представление ready photos и выдача подписанной ссылки оригинала. Публичные ответы не содержат email владельца и внутренних S3-ключей.
