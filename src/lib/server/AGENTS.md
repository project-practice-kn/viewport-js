# Серверные модули

Следуй корневому AGENTS.md.

- Открывай соединения лениво; миграции запускай отдельно от HTTP-запросов.
- Держи бизнес-логику в сервисах, а не в маршрутах.
- Проверяй доступ при каждой операции с данными.
- Не выполняй сетевые операции внутри SQLite-транзакций.
- Для SQLite + S3 сохраняй возможность повторить компенсацию после сбоя.
- Бинарные ответы и архивы передавай с учётом backpressure и отмены запроса; не буферизуй архив целиком.
