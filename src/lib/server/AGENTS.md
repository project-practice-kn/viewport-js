# Серверные модули

Следуй корневому AGENTS.md. Здесь реализованы auth, DB, галереи, обработка и S3.

При реализации: ленивые соединения, thin routes, проверки доступа в каждой операции, миграции отдельно от запросов, отсутствие сетевых операций в SQLite-транзакции и потоковый ZIP без полного буфера.
