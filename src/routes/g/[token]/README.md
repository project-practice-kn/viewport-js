# Публичная галерея

`+page.server.ts` вызывает publicGallery и photoViews из [сервиса галерей](../../../lib/server/galleries/index.ts). Без регистрации возвращаются название, описание, тема, обложка и упорядоченные ready previews. Неизвестный токен и снятая публикация дают 404. Страница рендерится на сервере; подписанные GET действуют 120 секунд.

С JavaScript PhotoSwipe открывает превью в просмотрщике: доступны двукратное увеличение, стрелки, Escape и сенсорные жесты. Качество увеличенного изображения ограничено разрешением превью. Кнопка скачивания запрашивает оригинал через существующий endpoint; при просмотре оригиналы не загружаются. Ссылки превью обновляются через защищённую повторной проверкой публикации страницу `previews`; при сетевом сбое доступна кнопка повтора. Без JavaScript ссылка открывает превью в новой вкладке, а для обновления ссылок требуется обновить страницу. Выбранная посетителем тема сохраняется в cookie и применяется на сервере при следующем открытии.
