# Публичная галерея

`+page.server.ts` вызывает publicGallery и photoViews из [сервиса галерей](../../../lib/server/galleries/index.ts). Без регистрации возвращаются название, описание, тема, обложка и упорядоченные ready previews. Неизвестный токен и снятая публикация дают 404. Страница рендерится на сервере; подписанные GET действуют 120 секунд.
